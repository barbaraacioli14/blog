# Meu Blog Azul

Um blog pessoal simples feito com HTML, CSS e JavaScript.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Escolha uma imagem, escreva uma legenda e clique em **Publicar**.
3. Escreva comentários no campo abaixo de cada publicação.

As publicações e os comentários ficam salvos no armazenamento local do navegador. Eles não são enviados para a internet e podem ocupar o espaço disponível no navegador; use imagens pequenas.
